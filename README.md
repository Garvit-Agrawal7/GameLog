## About

GameLog is a personal game tracking app with a dark cinematic UI. Search and add games from the IGDB database, track your library with completion statuses, log playtime, and discover new games through curated sections including trending titles, hidden gems, top RPGs, and similar games based on your recently completed games.

---

## Features

- Game search powered by IGDB
- Personal game library with completion status tracking
- Playtime logging
- Discover screen with trending, hidden gems, and top RPG sections
- Similar games recommendations based on recently completed games
